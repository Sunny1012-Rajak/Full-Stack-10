full stack development

Full Stack Development refers to the development of both front-end (client-side) and back-end (server-side) portions of web applications. They handle the complete development process, from designing user interfaces to managing databases and server-side functions, making them versatile in building end-to-end applications.

key layers of full stack development
  • HTML stands for HyperText Markup Language and is used to design the front-end structure of web pages.
  • CSS, or Cascading Style Sheets, is a simple language used to make web pages visually presentable.
  • JavaScript is a famous scripting language used to create the magic on the sites to make the site interactive for the user.
frontend libraries and framework

Make UI responsible using grid system.

  1. AngularJS is an open-source JavaScript front-end framework mainly used for building single-page applications (SPAs).
  2. Bootstrap is a free and open-source tool collection for creating responsive websites and web applications.
  3. jQuery is an open-source JavaScript library that simplifies interactions between HTML/CSS (the DOM) and JavaScript.
Other Important Points of full stack development
    • Work with text editors to use shortcuts and its facilities i.e. Visual studio, Atom, Sublime et
    • Git and git commands like init, add, commit etc for version control and to work with team.
    • Other tools like npm & yarn package managers, sass css pre-processor, browser DevTools i.e. chrome devtools.
    • Understand using HTTP, JSON, GraphQL APIs to fetch data using axios or other tools.
